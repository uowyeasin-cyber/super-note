# Super Note — Android app

Expo SDK 58 (React Native 0.88), Expo Router, SQLite, on-device speech, and a native reminder engine.

## What is in v0.1 (beta)

- **Voice notes** in English or Bangla (`expo-speech-recognition`, the phone's own speech service). Typing works too.
- **Say several tasks at once.** An offline parser (`src/lib/parse.ts`) reads times in Bangla and English: "কাল সকাল ৮টায়", "সাড়ে ৯টা", "১০ মিনিট পরে", "every Friday 8 pm", "10 Dec".
- **Auto folders** into six life areas: Academic, Business, Skills, Social, Family, Personal (`src/lib/classify.ts`).
- **Optional AI.** Add your own free Gemini key in Settings for smarter reading. Without it everything still works offline.
- **Own reminder engine** (`modules/super-alarm`, Kotlin): exact alarms, three ring levels (notification, alarm sound, full-screen call style), escalation if not done, snooze and done buttons, daily and weekly repeats, re-armed after reboot, app update or clock change. Stable ids mean a reminder is never set twice.
- Light, dark and six accent colours. English by default, Bangla in Settings.

## Develop

```bash
npm ci
npm test            # parser and classifier tests (node:test)
npx tsc --noEmit    # typecheck
npx expo run:android
```

`android/` is generated by `expo prebuild` and is not committed.

## Build

Every push to `main` that touches `app/` runs `.github/workflows/android.yml`: tests, `expo prebuild`, `gradlew assembleRelease`, then publishes the APK as a GitHub Release. The newest beta is always at
`https://github.com/uowyeasin-cyber/super-note/releases/latest/download/super-note-beta.apk`.

Beta builds are signed with the debug key. A Play Store release needs a private upload key added as repository secrets.
