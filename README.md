# Super Note

**Say it once. The AI does the rest.**

Super Note is an AI life assistant for Android. Speak in English or Bangla and it writes the note, files it, sets the reminder, counts the money, drafts the message and builds the CV.

- **Live demo:** open [`demo/`](demo/) (English) or [`demo/bn.html`](demo/bn.html) (Bangla). Switch language in Settings.
- **Plans & prices:** https://yeasinarafatbd.vercel.app/super-note/

## Status

Design and clickable demo are done. The Android beta is in development. See [docs/ROADMAP.md](docs/ROADMAP.md).
